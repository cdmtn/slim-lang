Добавь паттерны. Типовой: x: int => ..., u: User => ... (проверка через тот же предикат типа, что и аннотации; привязка получает значение). Объектный с деструктурированием и вложенными паттернами: { role: Role.Admin, name } => ..., { kind: "circle", r } => .... Массивный: [] => ..., [first, ...rest] => ..., [a, b] => .... Диапазон и альтернативы: 1..10 => ..., "a" | "b" => .... Комбинация с when сохраняется. Паттерны проверяются сверху вниз, привязки видны только в своей ветке.

Полнота: расширь проверку на union типов и литералов, на Result (Ok/Err), на enum с данными, если они уже есть в репозитории (иначе оставь точку расширения и не придумывай её сейчас). Диагностика называет конкретный непокрытый случай. Недостижимая ветка после _ или более общего паттерна даёт предупреждение. Эффективность: lowering должен давать плоские if/else без аллокаций на успешном пути и не вычислять subject дважды. Не вводи новый движок проверки, используй предикаты из задачи о компиляции типов.
