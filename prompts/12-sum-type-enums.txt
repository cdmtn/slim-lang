Синтаксис: enum Shape { Circle(r: float), Rect(w: float, h: float), Empty }, смешивать с enum со значениями в одном объявлении нельзя (понятная ошибка). Конструкторы Shape.Circle(2.5) возвращают неизменяемое значение с тегом и полями, проверенными по типам параметров, как аргументы функций. Значения без данных (Empty) работают как раньше. Аннотация let s: Shape принимает любой вариант, Shape::Circle только Circle. match получает паттерны Shape.Circle(r) => ..., Shape.Rect(w, h) => ... с привязкой полей по позиции и по имени ({ r }), полнота проверяется по вариантам с названием непокрытого. toString и log показывают Circle(r: 2.5). Struct-поле типа Shape проверяется предикатом, соответствие варианта и типов его данных проверяется в verify. Сериализация в JSON ({ tag: "Circle", r: 2.5 }) и обратно через Shape.parse с валидацией. Реализация не должна использовать Proxy; вариант это обычный объект с общим прототипом на вариант.
