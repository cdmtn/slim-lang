Расширь struct в Slim: валидаторы в поле, readonly, трансформации типов и derive, /home/nihmadev/slim-lang. Сначала изучи разбор struct в src/parser.js и src/handlers/parserHandler.js, генерацию __def_struct__ в src/transform.js, __def_struct__, __typed__, Struct.new и verify в src/external/core.js, src/external/types.js, готовые типы в packages/slim/types/*.slim, test/struct-enum.test.mjs, test/struct-features.test.mjs, test/runtime-types.test.mjs, раздел README про defaults, extends и методы. Прочитай реальный код и составь карту: как хранятся scheme, specification, __defaults__, __methods__, как объединяются при extends. Сохрани все текущие формы struct (поля с *, ?, defaults, extends, методы), copyof и lock, и посторонние незакоммиченные изменения.

Часть первая, ограничения в поле. Синтаксис age: int where 0..150, name: string where len 1..50, tag: string where /^[a-z-]+$/, и несколько условий через and. Условия компилируются в предикаты из задачи о предикатах типов, а сообщение об ошибке называет нарушенное ограничение ("User.age expected int where 0..150, got 200"). Часть вторая, readonly: readonly id: int запрещает запись после Struct.new (на уровне экземпляра через Object.freeze поля или defineProperty, без Proxy); verify на чужом объекте это не затрагивает. Часть третья, трансформации типов: Partial<User>, Required<User>, Pick<User, "name" | "id">, Omit<User, "roles"> создают новые struct-определения со своими verify/new, поддерживаются в аннотациях и в Struct.verify. Часть четвёртая, derive: struct User derive (json, eq, hash, clone, debug) добавляет toJSON/fromJSON с валидацией, глубокое сравнение eq, hash, clone и читаемый debug; каждое производное подключается только по запросу, чтобы не раздувать экземпляры. Не конфликтуй с уже имеющимися copyof и методами пользователя: пользовательский метод побеждает derive и это явно сообщается предупреждением.

Тесты: граничные значения диапазонов, regexp, несколько условий, наследование условий через extends, readonly при new и при присваивании в strict и обычном режиме, Partial/Pick/Omit на struct с extends и вложенными struct, derive на вложенных структурах, циклы в clone/eq, сообщения ошибок.
